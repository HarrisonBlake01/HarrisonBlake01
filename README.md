## Featured project

### [Paperline](https://github.com/HarrisonBlake01/paperline) — AI document intelligence SaaS

[Live recruiter demo](https://paperline-demo.olveraproductions.com) · [Case study](https://github.com/HarrisonBlake01/paperline/tree/main/docs/portfolio)

Paperline turns PDFs, DOCX files, scans, and images into structured, cited, reviewable outputs. It includes:

- parsing and OCR fallback with page-level provenance;
- schema-guided extraction and cited retrieval chat;
- workspace-scoped authorization with Clerk and Supabase/Postgres;
- a read-only MCP boundary for agent clients;
- Stripe test-mode lifecycle reconciliation;
- deterministic evaluation, security regression tests, CI, and release evidence.

The public demo uses synthetic data and test billing. The repository documents implemented behavior, measured evidence, and unresolved production follow-ups separately.
